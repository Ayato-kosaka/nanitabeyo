# 料理コピー調査アンケート - 手動テスト手順

## 概要

`/app-expo/app/[locale]/tools/dish-copy-survey.tsx` の動作を手動で確認する手順です。

## 前提条件

1. **開発環境セットアップ完了**
   - Node.js, pnpm がインストール済み
   - `pnpm install --frozen-lockfile` 実行済み

2. **CDNデータ配置完了**
   - `dish-copy-survey-data.json` がGCSに配置済み
   - または、開発時はローカルサーバーでモックデータを提供

## テスト準備

### オプション1: 実際のCDNデータを使用

`DISH_COPY_SURVEY_DEPLOYMENT.md` の手順に従って、GCSにデータをアップロードしてください。

### オプション2: ローカルモックサーバーを使用（開発用）

開発時は簡易HTTPサーバーでモックデータを提供できます：

```bash
# 別ターミナルでモックサーバー起動
cd /tmp
python3 -m http.server 8000

# または Node.js の場合
npx http-server -p 8000 --cors
```

そして、`dish-copy-survey.tsx` の `CDN_JSON_URL` を以下に変更：

```typescript
// 開発用（ローカルサーバー）
const CDN_JSON_URL = "http://localhost:8000/dish-copy-survey-data.json";

// 本番用（GCS）
// const CDN_JSON_URL = "https://storage.googleapis.com/nanitabeyo-static/dish-copy-survey-data.json";
```

## 開発サーバー起動

```bash
cd /home/runner/work/nanitabeyo/nanitabeyo/app-expo
pnpm start
```

## アクセス方法

### Web ブラウザで確認（推奨）

1. 開発サーバー起動後、ブラウザで以下にアクセス：
   ```
   http://localhost:8081
   ```

2. 画面左側の "Open in web browser" をクリック

3. URLバーに以下を入力してアンケート画面に直接アクセス：
   ```
   http://localhost:8081/ja-JP/tools/dish-copy-survey
   ```

### Expo Go アプリで確認

1. スマートフォンに Expo Go アプリをインストール

2. QRコードをスキャン

3. アプリ内で `/ja-JP/tools/dish-copy-survey` に移動

## 既知の制約事項

1. **CDNデータ取得エラー時**
   - ネットワークエラーまたはCORS設定不備でデータ取得に失敗する可能性があります
   - エラー時はエラーメッセージが表示されます

2. **画像読み込み**
   - Wikimedia画像の読み込みに時間がかかる場合があります
   - 画像が表示されない場合はネットワーク接続を確認してください

3. **ログ送信**
   - ログは `useLogger` を通じてバックエンドに送信されます
   - 認証が必要な場合、ログインしていないと送信できません

## トラブルシューティング

### カルーセルが表示されない

- `react-native-reanimated-carousel` がインストールされているか確認
- `pnpm install` を再実行

### モーダルが開かない

- `useBlurModal` が正しくインポートされているか確認
- Expo Blur パッケージがインストールされているか確認

### データが取得できない

- CDN URLが正しいか確認
- ブラウザの開発者ツールでネットワークタブを確認
- CORS設定を確認

### 送信が成功しない

- ログイン状態を確認
- バックエンドAPIが起動しているか確認
- ネットワークタブでエラーレスポンスを確認
