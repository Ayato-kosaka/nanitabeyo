# 2026-09-02 外部調査知識の保存方針

市場・利用者・学術調査を、実装から復元できない再利用可能な知識として `docs/research/` に保存する決定。
対象はプロダクト、事業、UX の仮説を検証するときに繰り返し参照する原典つき資料である。

## 背景

[2026-08-23 の整理方針](20260823-documentation-cleanup.md) は、陳腐化した実装説明の堆積を止めるため、
保存可能な Markdown を 4 種類に限定した。一方、飲食店・料理選びに関する多数の外部調査はコードにも
Issue にも正を置けず、今後の調査設計、優先順位づけ、事業判断で反復利用する。単発の作業ログとして凍結すると、
新しい調査との比較や出典訂正ができない。

## 決定

1. `docs/research/` を設け、「外部調査知識」を第 5 の文書種類とする。
2. 各数値は一つのカタログだけを正とし、統合知見や調査票からは調査 ID で参照する。
3. 各調査に原典 URL、調査時期、母集団、標本数、質問形式、分母、限界、最終確認日を可能な範囲で付す。
4. 二次記事しか確認できない結果、条件付き母集団、ベンダー調査、意向と実行の混同を明示する。
5. オーナーは四半期ごと、または重要な新調査・プロダクト仮説の変更時に再確認する。リンク切れは代替原典へ更新し、古い結果は年次比較に必要な限り残す。
6. 実装仕様・設計解説・PR の完了報告は置かない。研究から実装を決めた場合、その決定は従来どおりコードコメントまたは Issue / PR に置く。

## 影響

- 大量の調査結果を出典と限界ごと再利用でき、同じ調査の再探索と数値の転記ずれを減らせる。
- 時点依存の外部情報を持つため定期確認コストが生じる。`docs/research/README.md` にオーナーと確認日を置く。
- 既存の「コードを読めば分かる文書は作らない」という原則は変えない。
