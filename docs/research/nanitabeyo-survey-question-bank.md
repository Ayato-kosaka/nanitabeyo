# 「なに食べよ」自社アンケート設問バンク 300

外部調査で答えられない「料理から決める価値」「保存から来店」「共同決定」「信頼と収益化」を検証するための設問・実験課題集。読者は自社調査を設計・発注・分析する担当者。
これは一度に全問を配る質問票ではない。共通核を通した後、目的別モジュールを無作為に割り当てる。

## このバンクの使い方

1. 調査で決めたいプロダクト判断を一つ書く。
2. `SCR`、`PRO`、`OCC` から必要な共通核を選ぶ。
3. 該当モジュールを一つ、長くても二つ選ぶ。
4. ブランド名・選択肢順・コンセプト提示順を無作為化する。
5. 自己申告だけで決めず、`OUT` と `EXP` または行動ログを組み合わせる。

### 推奨する調査プログラム

## 設計上の禁止事項

- 「SNS は店選びに重要ですよね」のように答えを誘導しない。
- 「Google / Google マップ」のような複合選択肢は、検索と地図を分けて測る。
- 認知、利用経験、直近利用、最重要、信頼、来店を一問でまとめない。
- 「保存した」と「後で見た」、「予約した」と「来店した」、「行きたい」と「行った」を分ける。
- 平均点だけで順位を作らない。絶対に必要な制約と、あると嬉しい好みを分ける。
- 食物アレルギー、宗教・健康等の理由を必須で聞かない。機能に必要な食事制約だけ任意で聞き、診断名は収集しない。
- 正確な自宅・現在地、同行者の連絡先、私的な SNS 履歴をアンケートへ入力させない。
- 18 歳未満を調べる場合は、このバンクをそのまま使わず、保護者同意・年齢相応の説明を含む別プロトコルを審査する。

### 標本割付

- 18〜69 歳を対象に、性別、年代、地域の最低セルを事前設定する。人口構成へ加重する本標本と、18〜29 歳の追加標本を分けて保存する。
- SNS 利用者、アプリ利用者、直近外食者だけに絞る場合、一般標本の利用率と同じ表に混ぜない。
- 月 1 回未満の外食者も基準調査には残し、課題がないのか、機会がないのかを区別する。
- グループ、子ども連れ、食事制約は出現率が低ければ追加募集する。追加標本を全体比率へ混ぜない。
- n は慣例で決めず、主要比較の基準率・最小検出差・有意水準・検出力・離脱率から事前算定する。

| OUT-01 / OUT-05   | 保存、地図への遷移             | 代理行動が本当に「決まった」を表すか             |
| SAVE-05 / 10 / 11 | 保存と再閲覧                   | 保存が収集で終わるか、後の来店へつながるか       |
| GROUP-18 / 19     | 共有リンクの開封・投票         | 参加率と公平感・合意時間が一致するか             |
| BOOK-08 / 10 / 16 | 外部遷移と復帰                 | 外部へ出た後の予約・来店を過大推定していないか   |
| OUT-11 / 13       | 後日の軽い確認                 | 事前のクリック・保存が期待一致と再訪へつながるか |

地図クリックを来店と同一視せず、保存を満足と同一視しない。最初の検証では、各代理イベントの陽性的中率と陰性的中率を来店後回答に対して求める。

## 分析計画

### 主要アウトカム

1. 料理決定率と店舗決定率
2. 決定までの実測時間
3. 条件充足率と重大制約違反率
4. 来店・予約確認率
5. 期待一致、選択後悔、再訪意向
6. 7 / 30 日後の保存再利用と再決定

### 必ず分ける集計

- 一般人口 / SNS 情報収集者 / アプリ利用者
- 発見 / 候補化 / 最終決定で使った媒体
- 初回店 / 再訪店
- 一人 / 二人 / グループ / 子ども連れ / 職場
- 昼 / 夜、日常 / 特別、当日 / 事前計画
- 明確な料理意向あり / 曖昧 / 完全未定
- 必須制約あり / なし
- 実来店 / 予約のみ / 外部遷移のみ / 未決定

### 報告規則

- すべての表に質問文、回答形式、分母、非該当・無回答、実査日を付ける。
- MA の割合を合計 100%にしない。行列項目の表示分割がある場合は項目ごとの分母を示す。
- 条件付きサブ標本は `n` と分岐条件を見出しに出す。
- 平均に加えて中央値・四分位を出し、時間・金額の外れ値処理を事前定義する。
- 探索的な多数比較は補正し、主要評価項目・除外基準・停止規則を実査前に固定する。
- 「有意でない」を「差がない」と言い換えず、信頼区間と最小検出差を併記する。
- セグメントは都合のよい事後切出しで命名せず、別標本または後続期間で再現する。
- 自由回答は二人以上でコードブックを作り、不都合な意見も原数とともに残す。

## インタビューで使う追問

質問票の選択肢を読み上げる前に、次を順番に聞く。

1. 「その日のことを、店を考え始める少し前から時系列で教えてください」
2. 「その瞬間、実際にスマートフォンで何をしましたか」
3. 「覚えている範囲で、どんな言葉や画像を見ましたか」
4. 「候補に入った店と外れた店は、何が違いましたか」
5. 「誰が何を言って、決まりましたか」
6. 「『何でもいい』の中に、避けたいものはありましたか」
7. 「保存したものを、次にどうやって見つけましたか」
8. 「情報が正しいか不安だった箇所はどこですか」
9. 「店に着いて初めて分かったことは何ですか」
10. 「同じ状況をもう一度やるなら、何を省きたいですか」

回答者に理想機能を設計させる前に、実際の一回、使った画面、候補を捨てた理由、妥協を聞く。許可がある場合だけ本人操作の画面を見せてもらい、アカウント名、連絡先、正確な位置、同行者の会話は記録しない。
